# Code of conduct

## Our commitment

NoxaPlus EnvSentinel is a tool for people who ship code and would rather not explain a leaked key on a Friday night. Participants are expected to keep discussions technical, specific, and respectful, regardless of experience, background, identity, or the size of the project they are working on.

## Expected behavior

- Assume good intent, but be precise about technical concerns.
- Critique the work, not the person. Explain the impact of a problem and, when possible, suggest a fix.
- Treat security reports as sensitive. Do not ask someone to paste a live credential, private key, or customer data into a public thread.
- When reporting a false positive, include the rule ID and a synthetic sample, not the real value.
- Follow the issue and pull request templates so reports stay actionable.

## Unacceptable behavior

- Harassment, insults, threats, or discriminatory language.
- Publishing private information, credentials, or personal data without permission.
- Deliberately derailing issues, spamming, or repeatedly ignoring maintainer guidance.
- Submitting content that is illegal or that violates GitHub's terms.

## Scope

This policy applies to issues, pull requests, discussions, commit messages, and any other project space. It also applies when representing the project in public.

## Reporting

Report unacceptable behavior to **NoxaPlus2025@gmail.com**. Include links or screenshots when possible. Reports are handled privately. Maintainers may edit or remove content, close discussions, or block accounts, and will explain the decision when it is safe to do so.

## Attribution

This policy is written for EnvSentinel and is not a verbatim copy of a template. It is informed by common open-source community guidelines, including the Contributor Covenant.
